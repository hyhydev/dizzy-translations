# Dizzy translations

This is where [Dizzy](https://dizzy.gg) gets translated. Every word the site shows lives here, one folder per language, and anyone who speaks a language and plays in a community on Dizzy can help.

You don't need to know how to code. If you can edit a text file in your browser, you can translate Dizzy, and [CONTRIBUTING.md](CONTRIBUTING.md) walks you through it step by step.

## Languages

Each language has a reviewer, someone who speaks it and reads every change before it goes in. A language shows up in the language menu on the site once enough of it is translated.

Want to add a language that isn't here? Open an issue with [I want to translate a new language](https://github.com/hyhydev/dizzy-translations/issues/new/choose) and we'll get it set up with you.

## Seen something wrong?

If a word or sentence on Dizzy reads badly in your language (or in English), open an issue with [This string is wrong in my language](https://github.com/hyhydev/dizzy-translations/issues/new/choose). Paste the text as you saw it, say where you saw it, and tell us what it should say if you know. You don't have to fix it yourself.
