# Dizzy translations

The words [Dizzy](https://dizzy.gg) shows, in every language it speaks other than
British English.

Nothing to translate lives here yet. The first language files arrive with the
sync from the site, and a full guide to translating follows them.

Until then: if a word on Dizzy is wrong in your language, or you would like to
translate Dizzy into a new one, open an issue with one of the templates.

Everything in this repository is under the MIT licence. Opening a pull request
offers your contribution under it.
